What is the Pirate Shop Token?

Pirate Shop Access is a chest reward that unlocks the Pirate Shop, the themed merchant added for this season. It is not purchasable — there is no shop listing, no bundle and no legitimate third-party sale. The only way in is to open chests and get the drop.

How to get it

  1. Play the current season's battle royale modes — the token rolls from standard treasure chests.
  2. Open as many chests per match as you can; chest density matters far more than playtime.
  3. Play during a Treasure Hour if one is live — the drop multiplier applies to chest rewards.
  4. Track your chest count so you know whether you are above or below the expected curve.

How the maths actually works

The chance of getting at least one token from n chests is:

P = 1 − (1 − 1/137,500)n

At 137,500 chests you are still only at about 63% — the expected value is not a guarantee. At 95,300 chests you cross 50%. This is the most misunderstood part of loot maths: the average number of chests is not the number that makes it likely.

Frequently asked questions

Are these drop rates official?

Yes. Epic published the full table on November 7, 2026. We quote it unchanged and label every number we calculated ourselves.

Does opening more chests improve my odds on the next one?

No. Each chest is an independent roll. There is no pity system and no rising rate.

Is a “power hour” the same as a Treasure Hour?

Yes — “power hour” is just what players call it. Epic's own name is Treasure Hour.

Does the Treasure Hour multiplier change the token rate?

It raises chest reward rates during the window. At 1.5x the token becomes 1 in 91,667; at 2x it becomes 1 in 68,750.

Can I buy the token?

No. Anything offering to sell you the token or “guarantee” the drop is a scam — there is no legitimate purchase path.

Why can't I find a search volume for this keyword?

Because the token was added on November 1, 2026. It is too new for any keyword tool to have data on it.

How long is the token available?

Until the season ends on December 5, 2026.

Where do your chest counts come from?

Chests per match is a player estimate, not an Epic figure. We say so wherever we use it.
