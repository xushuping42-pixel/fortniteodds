Treasure Hour Fortnite: Event Times, Boosts & Rewards

Updated November 24, 2026 · Treasure Hunters season reference

Treasure Hour in Fortnite is a limited event window that increases the chance of selected Treasure Hunters rewards. This evergreen guide keeps the schedule, rewards and rules together; exact dates belong in the schedule rather than the page title.

How to use a boosted session

  1. Verify the session date, start, end and multiplier from Epic. Use the full local date: late US sessions fall on Sunday in many countries.
  2. Choose a route with the chest locations and tracker.
  3. Compare the published rate with the token odds table. A boost increases a small probability; it does not guarantee a token.
  4. If access drops, read the Pirate Token activation guide before starting its limited access period.

When the event changes

Epic names December 5, 2026 as the season's end-event date. Do not assume a regular Treasure Hour happens on finale day. After this season, treat the numbers above as an archived event reference until Epic announces a successor event.

Frequently asked questions

Is Treasure Hour the same as Power Hour?

Players sometimes use Power Hour to describe these boosted sessions. Check the actual event name and current rules in Fortnite; old Power Hour schedules do not confirm a Treasure Hour time.

Does Treasure Hour boost every reward?

No. Epic currently lists a Pirate Shop Access boost of 1.5×, a weekly gold outfit boost of 7.5× and a weekly vehicle/decal boost of 10×. Other categories have no boost listed on that support page.
